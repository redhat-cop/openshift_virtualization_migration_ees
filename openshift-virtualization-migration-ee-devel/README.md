# OpenShift Virtualization Migration Development Image

This image is provided for the use of individuals building capabilities into the OpenShift Virtualization Migration Collection. It includes content from the latest available image without the `infra.openshift_virtualization_migration` collection being present. Capabilities have been added to "shadow" the location Ansible Automation Platform places project (`/runner/project`) to allow developers an ease of use when building and testing new integrations.
